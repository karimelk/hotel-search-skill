# Legacy Fallback Search (Use Only If SerpApi Is Blocked)

Use this file only when:
- `SERPAPI_API_KEY` is missing, or
- SerpApi quota is exhausted, and
- the user explicitly approves fallback.

Fallback queries:
- `best hotels in <city> <dates>`
- `<city> hotel free cancellation`
- `<hotel name> official site`
- `<hotel name> cancellation policy`

If fallback is used, clearly label results as **manual fallback (not SerpApi script output)**.
